# Tractive Demo App

A project to showcase demo usage of Tractive app.

# Description

The project contains 2 screens, one for asking the user whether they are dog or cat parents, the other for the cat choice.

# Getting Started

1. Make sure you hace Xcode 14.3 or above.
2. Make sure you have [SwiftGen](https://github.com/SwiftGen/SwiftGen) installed. Follow the link for more details.

# Architecture

MVVM architecture is used.
